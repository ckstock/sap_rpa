# SAP RPA V2 一键安装包关键功能说明

## 设计目标

这个安装包面向 Windows Server 上线，不绑定开发机路径。管理员只需要选择运行根目录和源码/发布包根目录，就能完成文件复制、协议注册、数据库初始化、本地 API 启动和上线检测。

## 安装器包含什么

| 文件 | 作用 |
| --- | --- |
| `启动一键安装器.bat` | 双击入口。通过 PowerShell ScriptBlock 读取安装器脚本，避免直接 `-File` 在部分执行策略下被拦截。 |
| `SapRpaServerSetup.ps1` | WinForms 图形安装器，同时支持 CLI 模式。 |
| `config.local.example.json` | 钉钉 OpenAPI 本机配置模板，只包含占位符。 |
| `README_服务器一键安装说明.md` | 面向管理员的点击步骤、命令行参数和验收方式。 |
| `关键功能说明.md` | 面向项目交接的功能边界说明。 |

## 核心能力

1. 路径可配置：服务器根目录由管理员填写或选择，`D:\sap_ai` 只作为开发机示例。
2. 部署可保留状态：默认保留 SQLite、日志、输出文件、SAP DPAPI 登录配置和 `config.local.json`。
3. 重置有独立入口：清库或重建 SQLite 必须走“备份并重建 SQLite”，不会混进普通升级。
4. SAP 登录本机保护：SAP 密码只写到当前 Windows 用户的 DPAPI 配置，不进入网页和 Git。
5. API 本地启动：通过 `SapWebLauncher.exe --serve` 启动本地 HTTP API。
6. SAP GUI 串行执行：安装包只负责部署，真正执行仍由 SapWebLauncher 串行队列控制，避免多人同时操作一个桌面 SAP 会话。
7. 钉钉参数本机化：真实 `appKey/appSecret/agentId` 只在目标服务器本机配置，Git 里只放占位模板。
8. 诊断可复制：安装器日志写入 `logs\installer-gui.log`，排查时不用只看截图。

## 运行目录结构

```text
<SAP_RPA_HOME>
  index.html
  bin\
    SapWebLauncher.exe
    *.dll
  transactions\
    ZFI072A.vbs
    transaction-config.json
  data\
    sap-rpa-config.db
  logs\
    installer-gui.log
    launcher.log
  outputs\
  backups\
  config.local.example.json
  config.local.json   # 仅服务器本机，可选，不提交 Git
```

## 上线注意事项

- SAP GUI 自动化必须在已登录的交互式桌面会话里运行，不适合直接做成普通 Windows Service。
- 如果服务器只允许签名脚本，当前 `.bat + ScriptBlock` 入口应由 IT 改成签名脚本或编译 EXE 入口，安装器逻辑可以复用。
- 如果从 Git 拉取源码部署，服务器需要 .NET 8 SDK 用于构建 SapWebLauncher；如果使用发布包部署，应提前带上已编译的执行器文件。
- 真实密钥、真实服务器地址、SAP 密码、数据库和日志都不应提交到 Git。
